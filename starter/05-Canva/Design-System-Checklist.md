# Photo Rules

- [ ] Skin tone stays stable across posts
- [ ] No extreme beauty filters that change identity
- [ ] Lighting family consistent (e.g. natural daylight, soft cinematic)
- [ ] Outfit categories defined (casual / elevated / sport / evening)
- [ ] Backgrounds match niche (travel, studio, café, gym…)

\newpage

# Typography Rules

- [ ] Max 2 fonts account-wide
- [ ] Title case or sentence case — pick one
- [ ] Avoid all-caps walls of text
- [ ] Line length short for mobile
- [ ] Text contrast AA-ish (readable in sunlight)

\newpage

# Logo & Watermark

**Policy (choose one):**

- [ ] No watermark
- [ ] Small corner mark on selected posts only
- [ ] End-frame logo on Reels only

Never place marks over the face.

\newpage

# Layout Rules

- [ ] Consistent margins (e.g. 60–80 px on 1080 designs)
- [ ] Face not covered by stickers
- [ ] One focal point per frame
- [ ] Carousel title position locked
- [ ] Highlight covers share one icon style

\newpage

# Do / Don’t

| Do | Don’t |
|----|-------|
| Let the AI photo lead | Cover 40% of the image with text |
| Use brand colors sparingly | Rainbow every post |
| Crop bad AI artifacts | Hide mistakes under stickers |
| Match caption voice to visuals | Loud meme fonts on luxury niche |
