Chapter 10 — Face Consistency Prompts

Prompt 91 — Identity Lock Instruction

Maintain identical facial identity across all images.

Same:
- facial proportions
- eyes
- nose
- mouth
- skin tone
- jawline
- age appearance

Only change:
- clothing
- environment
- pose
- lighting

Prompt 92 — Base Character Anchor

Use the same AI influencer identity in every image:
[Name], [Age], [Nationality], [hair color and style], [eye color], [skin tone], [face shape], [signature style].
Keep the face consistent and recognizable.
Only change the scene, outfit, and pose.

Prompt 93 — Reference Image Style

Create a new image using the same facial identity as the reference character.
Preserve the same eyes, nose, lips, face shape, skin tone, and age.
Change only the outfit, background, camera angle, and mood.
Ultra realistic lifestyle photography.

Prompt 94 — Character Sheet Prompt

Create a character reference sheet for a realistic AI influencer.
Show front view, slight side view, and smiling portrait.
Same face in all views.
Neutral background.
Consistent hair, eyes, skin tone, and facial proportions.
High detail.

Prompt 95 — Facial Detail Reminder

The subject must look like the same person as previous images.
Preserve:
- same eye shape
- same eyebrow shape
- same nose bridge
- same lips
- same cheekbones
- same skin tone
- same approximate age
Realistic photography, no face swapping, no identity drift.

Prompt 96 — Outfit Change Only

Generate the same AI influencer in a new outfit.
Do not change the face, age, hair color, eye color, skin tone, or facial structure.
Only change clothing, accessories, pose, and background.
Natural realistic photography.

Prompt 97 — Location Change Only

Place the same AI influencer in a new location: [location].
Keep identical facial identity, hair, eyes, skin tone, and body proportions.
Change only the environment, lighting, outfit, and pose.
Instagram travel photography.

Prompt 98 — Brand Campaign Consistency

Create a brand campaign image featuring the same AI influencer.
Keep the character visually identical to previous posts.
Consistent face, hairstyle, skin tone, and age.
Add [product] naturally into the scene.
Commercial lifestyle photography.

Prompt 99 — Negative Drift Prevention

Avoid changing the person.
Avoid different face, different age, different ethnicity, different eye shape, different nose, different lips, different skin tone, or different hairstyle.
Keep the influencer recognizable as the same person.
Only vary pose, outfit, and background.

Prompt 100 — Master Consistency Prompt

Create an ultra realistic image of the same AI influencer character.
