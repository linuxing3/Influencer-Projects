Canva Template Briefs

Five Layouts to Recreate Once and Reuse

These are text specs, not Canva binary files. Build each once in Canva, save as a Brand template or folder favorite, then duplicate weekly.

Template 1 — Feed Portrait Cover

Spec Value
Size 1080 × 1350
Background Full-bleed AI photo
Text Optional 1 short line bottom third
Scrim Soft gradient only if text needs contrast
Use Lifestyle, portrait, soft promo

Build notes: face upper-center; 80 px side margins; no more than ~8 words of text.

Template 2 — Quote / Soft Statement

Spec Value
Size 1080 × 1350
Background Calm portrait or blurred lifestyle still
Text Quote 2–3 lines, centered or lower third
Font Heading font, medium weight
Use Mindset, brand voice, save-worthy lines

Build notes: keep quote under 20 words; character name small at bottom optional.

Template 3 — Carousel Slide System

Spec Value
Size 1080 × 1350 per slide
Slide 1 Big number or hook + tiny subtitle
Middle One tip / step / item per slide
Final CTA: Save · Comment · Follow · Link in bio
Chrome Same top bar or page dots style optional

Build notes: lock title Y-position; max 25 words per middle slide; brand color accent bar OK.

Template 4 — Reel Cover

Spec Value
Size 1080 × 1920
Focal Face or clear subject center-safe zone
Text 3–6 word hook, large
Safe zone Avoid top/bottom UI areas
Use First frame / custom cover upload

Build notes: readable at thumbnail size; high contrast; no tiny body text.

Template 5 — Story CTA

Spec Value
Size 1080 × 1920
Layout Photo top 60% · message mid · sticker space lower
Text One question or CTA
Interactive Leave room for poll / link / question sticker
Use New post push, promo, Q&A

Build notes: design empty lower zone for Instagram stickers; do not pre-draw fake buttons that confuse users.
