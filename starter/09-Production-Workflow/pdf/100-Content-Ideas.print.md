# 100 Content Ideas

## Pillar-Based Idea Bank for AI Influencers

Use these as starting angles. Replace brackets like `[city]`, `[niche tip]`, `[product]`, or `[outfit]` with your character details.

**Format key:** F = feed photo · C = carousel · R = Reel · S = Story

Keep one fixed base character description on every visual.

# How to Use This Bank

1. Pick **3–5 pillars** that match your niche (not all 10).
2. Highlight 20–30 ideas for the next month.
3. Copy them into `04-Calendar/30-Day-Content-Calendar.md`.
4. Attach a prompt from `02-Prompts` and a caption starter.
5. Retire ideas that flop; promote winners into formulas (`Content-Idea-Formulas.md`).
