# Production Workflow

This folder is the **entry point** for the full AI influencer production system.

## Two paths

| Path | Who | Start here |
|------|-----|------------|
| **Buyer / creator** | You bought the toolkit or are launching your first AI influencer | `AI-Influencer-Production-Workflow.md` |
| **Operator** | You run an influencer weekly (batch, QA, publish, review) | `../09-Ops/PRODUCTION-SOP.md` |

## How the kit fits together

```text
01-Workbook     → define character, niche, pillars, monetization
00-Character    → visual pack / LoRA prep (optional)
02-Prompts      → image prompts, captions, hooks, X templates
03-Content-Ideas→ idea bank + formulas
04-Calendar     → 7-day launch + 30-day + weekly batch
05-Canva        → sizes, design system, layout briefs
09-Ops          → operator SOPs, quality gate, publish checklists
```

## Recommended order

1. Read `AI-Influencer-Production-Workflow.md`
2. Complete the workbook worksheets in `01-Workbook/`
3. Pull ideas from `03-Content-Ideas/`
4. Fill a calendar in `04-Calendar/`
5. Generate images with `02-Prompts/`
6. Polish in Canva with `05-Canva/`
7. Publish with Instagram as primary (see workflow + `09-Ops`)

Keep it simple: **one primary platform, one character, one weekly batch.**
