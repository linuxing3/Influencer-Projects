# Repurpose Matrix

Instagram is the **source of truth**. Secondary channels only after the IG weekly loop is stable (usually week 2+).

Do not create fully separate content systems per platform at the beginning.

---

## Matrix

| Source (Instagram) | → X | → TikTok | → YouTube Shorts | → Stories (same day) |
|--------------------|-----|----------|------------------|----------------------|
| Feed photo | Opinion or caption hook as text post | Optional slideshow / still video | Rare | Still + “new post” |
| Carousel tips | Thread: 1 tip per post | On-screen text video | Same as TikTok | Swipe-through teaser |
| Reel | Hook line as text + link if allowed | Native re-export (check ratio) | Re-export 9:16 | Clip + poll |
| Soft promo | Honest mini-review thread | Demo-style short | Demo-style short | Link sticker if available |
| BTS / process | “How I make content” notes | Screen-style process cut | Same | Casual frames |

---

## Rules

1. **Change the hook** when you repost video — do not dump identical first frames everywhere if the platform allows a custom cover.
2. **Respect disclosures** on every platform where the promo appears.
3. **Native text:** X wants tighter copy; use `02-Prompts/Bonus-50-Viral-X-Post-Templates.md`.
4. **Video hooks:** use `02-Prompts/Bonus-30-YouTube-Hooks.md` for Shorts/TikTok openings.
5. **Volume cap:** secondary channels should not double your production time. Cap at 30 minutes repurpose per batch day.

---

## Weekly repurpose checklist

- [ ] Pick top 2 IG pieces worth repurposing
- [ ] Write X variants (if using X)
- [ ] Export Reel for TikTok / Shorts if using video
- [ ] Adjust on-screen text safe zones if needed
- [ ] Log where each piece went

---

## When *not* to repurpose

- Face failed quality gate on IG (fix first)
- Promo already hit the 20% budget and secondary would stack more selling
- You are behind on primary batch — protect Instagram first
