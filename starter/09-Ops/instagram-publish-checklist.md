# Instagram Publish Checklist

Use for every feed post, carousel, or Reel.

---

## Before upload

- [ ] Asset from `04-ready` only (passed quality gate)
- [ ] Caption final (voice locked)
- [ ] CTA decided: none · save · comment · link in bio · share
- [ ] Hashtags ready (5–15)
- [ ] Alt text written (describe scene + character accessibly)
- [ ] Cover chosen for Reels
- [ ] Promo disclosure included if paid / gifted / affiliate requires it

## Account hygiene (spot-check weekly)

- [ ] Profile photo still best face reference
- [ ] Bio matches current niche
- [ ] Link in bio works
- [ ] Highlights not empty chaos

## Upload steps

1. [ ] Create post / Reel in app or scheduler
2. [ ] Confirm crop (4:5 feed or 9:16 vertical)
3. [ ] Paste caption
4. [ ] Add alt text
5. [ ] Tag products / people only if intentional
6. [ ] Location tag only if authentic to the scene
7. [ ] Share to Story (optional recommended)
8. [ ] Publish

## First 15 minutes

- [ ] Pin or post first comment (hashtags or extra CTA) if that is your system
- [ ] Reply to early comments
- [ ] Engage 5–10 niche accounts (genuine)
- [ ] Save any audience questions as ideas
