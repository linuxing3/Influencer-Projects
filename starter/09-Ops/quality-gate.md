# Quality Gate

Run on every asset before Canva polish and again before publish. One failed critical item = regenerate or crop — do not post.

---

## Visual — Critical

- [ ] **Face** matches reference set (shape, eyes, nose, mouth)
- [ ] **Hair color / usual style** stable
- [ ] **Eye color** stable
- [ ] **Skin tone** stable (no random filter shift)
- [ ] **Age range** looks the same
- [ ] No extra limbs, melted hands, or deformed fingers (or hands cropped out)
- [ ] No random text, watermarks, or logos from the generator
- [ ] No duplicate faces / ghost artifacts

## Visual — Brand

- [ ] Outfit fits niche and style rules
- [ ] Lighting family on-brand
- [ ] Background makes sense for the story
- [ ] Image is sharp enough on mobile
- [ ] Cropping does not cut off important features awkwardly

## Copy

- [ ] Caption sounds like the character voice
- [ ] One clear idea (not three CTAs at once)
- [ ] Promo posts disclosed when required (`#ad`, paid partnership)
- [ ] Spelling checked for on-image text
- [ ] Hashtags relevant (not only mega-tags)

## Platform

- [ ] Correct aspect ratio for destination
- [ ] Safe zones respected (Stories / Reels)
- [ ] Alt text drafted
- [ ] Filename + calendar row match
- [ ] Soft promo within weekly 20% budget

---

## Severity

| Level | Examples | Action |
|-------|----------|--------|
| Blocker | Wrong face, horror hands, unreadable mess | Reject |
| Major | Off-brand outfit, harsh filter | Fix or regenerate |
| Minor | Slight crop, caption tweak | Fix in Canva / copy |

**Operator rule:** if you have to squint to accept the face, it is a reject.
