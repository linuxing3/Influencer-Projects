# 3 — Batch Session Checklist

## Plan (30–45 min)

- [ ] Ideas selected and mixed across pillars
- [ ] 80/20 promo check passed
- [ ] Publish days assigned

## Generate (45–90 min)

- [ ] Base prompt pasted every time
- [ ] Images generated per idea
- [ ] Weak outputs deleted
- [ ] Winners saved to `01-raw` → `02-approved`

## Quality gate (15–20 min)

- [ ] Face consistent
- [ ] Hands / artifacts checked
- [ ] Lighting / outfit / niche fit
- [ ] Full gate: `09-Ops/quality-gate.md`

## Canva (30–45 min)

- [ ] Correct Instagram sizes
- [ ] Overlays only when needed
- [ ] Export to `03-canva` / `04-ready`

## Captions (20–30 min)

- [ ] Voice matches character
- [ ] CTA set (or none)
- [ ] Hashtags prepared
- [ ] Optional first comment written
